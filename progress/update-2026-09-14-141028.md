  spirit to `scripts/build_notebook.py`'s -- then one genuine `_ = ask(question, label)` code
  cell per case (one line per turn for multi-turn cases). The already-captured real output from
  the live run is still attached to each cell (so it reads correctly without needing to
  re-execute), but the *source* is real, executable code -- re-running the notebook with a live
  key would make real new calls, not just redisplay static text.
- `scripts/build_high_level_notebooks.py`: same fix applied to its condensed 1-2-example-per-
  capability cells, reusing the same `SETUP_SOURCE`/`ASK_HELPER_SOURCE` constants (imported
  from `build_capability_notebooks.py` rather than duplicated).
