### B. Two-Tier Model Governance & Allocation
We established a strict two-tier model allocation strategy under Token Harbor to optimize intelligence while protecting rate limits:

| Role | Model Configured | Intelligence Index | Target Workloads & Rationale |
|---|---|---|---|
| **Router Model** | `deepseek-v4.1-flash:free` | **39.5** (Rank #21) | • NLU intent classification & multi-agent routing<br>• Ambiguous query clarification generation<br>• Multi-source evidence synthesis with inline citations<br>• Corrective synthesis retry upon numeric hallucination detection |
| **Worker Model** | `deepseek-v4-flash:free` | **35.0** (Rank #32) | • NL $\rightarrow$ safe SQL generation against fixed 4-table SQLite schema<br>• Rolling transcript compression (`memory_summarizer`)<br>• Sandboxed Python snippet generation (`coding_agent`) |

*Result*: Preserves scarce V4.1 quota by running high-volume, narrow tasks on unconstrained V4, applying top-tier intelligence exclusively to complex reasoning choke points.

## 3. UI Framework Decision Matrix (Streamlit vs. Gradio)

To satisfy the user request for an interactive UI featuring an agentic **Developer Mode**:

| Evaluation Dimension | Streamlit | Gradio | Decision / Advantage |
|---|---|---|---|
| **Package Weight (Dry-Run)** | **16 packages** | 30 packages (pulls `huggingface-hub`, `pydub`, `ffmpeg`) | **Streamlit**: 47% fewer dependencies, clean resolution via `uv`. |
| **Agent Observability Primitives** | Native `st.status()`, `st.expander()`, `st.toggle()`, `st.metric()` | `gr.Accordion()`, `gr.JSON()` | **Streamlit**: Purpose-built for multi-step agent thought visualization. |
| **Development Time (LOC)** | **~150–180 lines** | ~250–300 lines | **Streamlit**: Estimated completion in **45–60 minutes**. |
| **State Synchronization** | `st.session_state` natively maps to `Orchestrator` & `ConversationMemory` | Complex tuple/dict transformations | **Streamlit**: Zero friction session filter persistence. |
| **Aesthetic Fit** | Polished enterprise BI dashboard (AB InBev branding) | ML research / demo playground | **Streamlit**: Aligns with FMCG executive analytics portals. |

**Verdict**: Proceeding with **Streamlit** to build `app.py`.
